# GoConnect 1.0.2（build 59）

发布日期：2026-11-06。

本版更新原生菜单栏图标，并提供可选的当前线路速率显示，延续 1.0.1 的团队开发签名和 GitHub 签名在线更新。

## 更新内容

- 菜单栏使用透明的单色路径 G／端点图标，随 macOS 菜单栏着色；保留未连接、连接中、已连接和注意状态徽章。
- 设置 → 菜单栏新增“显示网络速率”，**默认关闭**。
- 开启后可选“下行与上行”“仅下行”“仅上行”，方向选择自动保存；单向显示占用更少空间，关闭后恢复仅图标并保留方向。
- 速率沿用当前 GoConnect 线路的上下行采样，不代表整台 Mac 的总网速。样本过期、断开、恢复中或没有数据时显示“—”，真实零值显示 `0 B/s`。
- 固定显示槽位和等宽数字避免速率变化时菜单栏频繁抖动，工具提示和辅助功能保留所选方向语义。

## 安装与更新

Apple Silicon 应用包要求 macOS 26 或更新版本。已经安装 1.0.1 的用户，先断开 VPN 并保存线路草稿，再从 **GoConnect 菜单或设置 → 检查更新** 下载并确认安装重启。自动检查默认关闭，可在设置中开启；下载和安装仍由用户确认。

0.11.17 及更早没有更新器，需正常断开、退出并手动替换一次 App。更新应用后，如诊断页提示网络组件有新版本，按正常流程升级本机网络服务，可能需要管理员授权。应用、helper 与用户数据分别管理，不以更新覆盖已有线路、订阅或流量历史。

## 签名与验收边界

沿用团队 `RX44JC39GB` 的 **Apple Development 开发签名**和 Hardened Runtime，更新 ZIP 与整个 feed 分别使用既有 Ed25519 密钥签名。未采用 Developer ID 分发签名，未经过 Apple 公证；本机验收不代表其他 Mac 的首次安装信任行为已验证。

发布门槛包括完整脚本／Swift／Go race／打包检查、严格嵌套签名、适用原生菜单栏验收、隔离 App 的真实 1.0.1 → 1.0.2 下载／验签／安装／重启，以及公开附件与固定更新源的匿名回验。真实线路保持当前会话，由用户在 GoConnect 中执行正式更新。

此前菜单栏隔离验收覆盖默认关闭、三种方向、实时切换、偏好持久化、5 秒过期、零值、极值及浅深色模板图标；数据为合成样本，不代表实链路测速。菜单项拥挤、不同刘海屏和所有 macOS 外观组合未逐机覆盖。

**AnyConnect UDP 稳定性仍是已知限制，未修复、未重新验收。** 本版不把 HY2 或 HTTPS 成功扩大为 AnyConnect UDP 通过；服务商剩余套餐余额也不属于本机流量统计。
