# GoConnect 1.0.8（build 68）

透明分流连接现在接管 macOS 系统默认 DNS。未设为直连的公网域名（包括 OpenAI、Anthropic、Gemini）通过当前代理的加密 DoH 解析；DNS 查询失败时不会静默回退到本地运营商。

已有国内直连域名继续使用原解析器，局域网、单标签主机名和已有私有域名解析路径保留。网站及应用的流量分流规则不变。使用临时系统 DNS 记录，断开或 worker 异常退出后恢复原解析，不改写网络偏好。

升级网络组件后，请在诊断页按正常流程更新本机网络服务。可以保持 VPN 检查和下载更新，最终安装重启仍需确认并正常断开。自动检查默认关闭，现有签名更新源和公钥不变。

适用于 Apple Silicon / macOS 26 及以上。沿用团队 RX44JC39GB 的 Apple Development 签名与 Hardened Runtime，并提供 Ed25519 签名 ZIP 和更新源；不是 Developer ID 分发签名，未经过 Apple 公证。

验收覆盖分流 DNS、代理失败时的防回退、macOS 原生解析及临时记录恢复、连接生命周期、完整回归、隔离真实 OTA，以及发布和固定更新源的签名/字节回验。验证细节见 [系统 DNS 说明](SYSTEM_DNS_2026-11-07.md)。

边界：应用自带的 DoH/DoT、指定接口解析、用户主动配置的直连域名不等同于系统默认 DNS 保护；不宣称全部应用零泄漏。未新增企业 VPN 内部 DNS 配置能力。AnyConnect UDP 历史限制未修复、未重新验收。
