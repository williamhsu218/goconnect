# GoConnect 1.0.17 (build 77)

- 诊断页新增代理 HTTPS、代理 DoH 和原网络 HTTPS 对照，显示结果和耗时。系统每 45 秒抽测一次，代理探测两次连续失败后，连接页和菜单栏显示「线路降级」，恢复后自动更新。
- 识别底层网络变化后，GoConnect 会先等待旧会话完成清理，再等新网络稳定，并尝试恢复当前线路和分流配置。订阅线路最多尝试三次，AnyConnect 可使用已保存的凭据尝试一次。恢复窗口最长约 50 秒，可随时取消。公司副连接在主线恢复后按正常流程重新连接。
- Apple Silicon，macOS 26.0 或更高版本。沿用 Apple Development 团队签名及 Hardened Runtime。应用压缩包和更新源均使用 Ed25519 签名，应用未经过 Apple 公证。
- 可以在原 VPN 正在使用时检查和下载更新。确认安装重启时，GoConnect 会按正常流程结束当前连接。更新后如提示本机网络服务版本不符，请按诊断页提示升级服务，再重新连接。
