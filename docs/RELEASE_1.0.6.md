# GoConnect 1.0.6（build 65）

发布日期：2026-11-06。

菜单栏快捷菜单在“诊断”下方增加“设置…”入口及标准快捷键 ⌘,，可直接打开和前置原生设置窗口。主窗口关闭后仍可使用；重复点击复用设置窗口，不启动额外实例，不改变 VPN 连接。

使用 SwiftUI 的 openSettings 环境动作，经应用生命周期持有的入口调度；不模拟键盘，不使用私有设置选择器，不另造设置窗口。

包含 1.0.5 的 IPv4 网络下 TUN 内部双栈修复，以及固定 77pt、保留 MB/s 等单位、不显示四位速率数字的紧凑菜单栏。网络规则、配置数据、统计口径和更新器逻辑不变。

## 安装与验证范围

Apple Silicon，macOS 26 或更新版本。在 GoConnect 内检查更新，可保持 VPN 检查、下载和验签，确认安装后正常断开并重启。网络服务如提示新版本，按正常本机授权流程升级。

沿用 RX44JC39GB 的 Apple Development 团队签名、Hardened Runtime 与原 GoConnect Ed25519 更新密钥；ZIP 与完整 feed 分别签名，生产公钥、固定更新 URL、stable 渠道不变。未采用 Developer ID，未做 Apple 公证。

适用发布门禁：完整构建/测试及严格嵌套签名；实际菜单入口、关闭主窗口及重复打开设置；隔离真实 OTA；四附件公开读回和固定签名更新源回验。预览为独立测试应用，不含真实网络或凭据实现。1.0.5 已完成本机 Tokyo Japan 的实际双栈路由、连接及清理验收；本版网络实现仅生成版本常量变化。AnyConnect 真实 UDP 仍按用户决定跳过，未修复、未重新验收。

附件：应用 ZIP、对应第三方源码包、已签名 appcast.xml、SHA256SUMS。
