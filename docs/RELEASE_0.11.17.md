# GoConnect 0.11.17（build 57）预发布版

发布日期：2026-11-06。

本版采用浅色精密方向调整原生 macOS 界面，增加按线路保存的本机流量统计，并明确代理名单的名称。

## 更新内容

- 调整连接页、线路列表、订阅页和诊断页的布局、层级、工具栏及状态提示，保留原生侧栏、表单、菜单和窗口行为。
- 将“应用白名单”改名为“代理应用与服务”，对应分流模式显示为“按名单代理”。配置中已有的 whitelist 标识、名单和路由规则保持兼容。
- 移除界面中的订阅剩余套餐和登录授权入口，改为显示每条线路在本机记录的接收、发送和合计用量，支持分时、日、月、年查看。
- 流量记录保存在本机 SQLite 数据库，断线与重新连接后累计保留；历史线路可以只读查看，不会因此切换正在使用的 VPN 线路。
- 新统计从本版开始记录，无法补回旧版本、其他设备或运营商计费数据。计数暂不可用、没有记录与实际零流量分别显示。它是评估用量的参考，不等同于套餐账单。
- 不更改连接协议、透明分流、恢复流程或现有配置格式；相对 0.11.16，Transport 目录仅更新产品版本常量。

## 已知限制

**AnyConnect 的真实 UDP 稳定性门禁仍未通过。** 本版继续作为预发布版，不将界面验收和隔离测试扩大为企业 VPN 长时间稳定性结论，也不替换保留的正式版验收结论。

本机统计不能知道服务商套餐上限、计费周期、扣费倍率或其他设备的使用量。切换系统时间、时区和统计暂不可用也会影响时间归属或记录完整性。

## 下载与安装

- `GoConnect-0.11.17-macos-arm64.zip`：Apple Silicon 应用包，要求 **macOS 26 或更新版本**。完整包要求高于源码的 macOS 14 部署目标。
- `GoConnect-0.11.17-third-party-sources.tar.gz`：第三方源码、补丁、配方、许可证、SBOM 和实际链接的 Go 依赖。
- `SHA256SUMS`：运行 `shasum -a 256 -c SHA256SUMS` 校验完整下载的两个附件。

更新前先断开 GoConnect 并退出，再替换“应用程序”中的旧版。按“诊断”页提示更新本机网络服务。线路、订阅缓存、钥匙串与应用包分别保存；应用包回滚不等于用户数据或网络服务回滚。

应用使用本地 ad-hoc 签名，未经过 Apple Developer ID 签名或 Apple 公证。请核对下载来源。本项目不提供关闭系统安全保护的安装方法。

## 验证

发布候选已通过 Swift 112 项测试、28 项 Python 脚本测试、Go race、严格签名、运行组件检查及隔离集成检查。需要实际系统分流的条件测试按环境跳过。界面在独立测试 App 中完成原生渲染、交互、草稿保护及流量统计检查，不能据此推断所有网络或设备均已覆盖。

公开源码的示例地址使用文档地址及示例标识；脱敏后的用量同步端 9 项与 Swift 7 项相关测试通过。公开快照的产品 Sources 与构建候选的 Sources 逐文件一致。

发布候选已替换本机旧安装本并完成运行验收：76份应用文件与候选逐文件一致，配套网络服务更新并正常连接原订阅线路；真实代理请求取得 HTTP 204，本机流量累计落盘并通过 SQLite 检查。连接页、代理名单及分时、日、月、年统计均已在安装版核对。安装初次回读确认原配置、订阅和旧凭据保持一致。

第三方依赖与 0.11.16 一致。源码附件复用上版同一内容，内部顶层目录仍为 `GoConnect-0.11.16-third-party-sources`；已逐项核验 15 份上游源码/补丁、122 个 Go 模块的 SHA-256 与 h1，以及实际链接依赖、SBOM、许可证和精确版本配方。GoConnect 自身的源码变更以本版 Git 标签为准。
