# GoConnect 1.0.9（build 69）

加入“公司副连接”试用功能，默认关闭。可在 HY2 主线路上连接一条独立 AnyConnect 公司线路，分别控制连接、认证与会话流量；只为用户明确批准的 IPv4 私网和公司域名预留公司出口。公司 DNS 可以从认证后的公司服务器获取，也可手动指定。本阶段公司业务只支持 IPv4 / TCP。

已实现公司出口未就绪时拒绝转发、公司 DNS 查询不回落至公网、断开前阻断确认、后端身份变化与退出检测、草稿和更新交接保护。已通过源码、隔离真实组件、自动化回归和主要界面检查；**系统双 VPN 路由、原生公司 DNS、真实公司业务 / SMB、睡眠恢复和退出清理尚未完成真实场景验收**。本轮按维护者明确选择“先发布、在线更新后验收副 VPN”的顺序交付，不把待验收项写成通过。

## 更新后开始测试

1. 可保持当前 VPN 检查、下载和验签；确认安装重启后才由应用正常断开。安装和下载不会自动执行。
2. 新版包含网络组件变化，请先按“诊断”页提示更新本机网络服务。先保持公司副连接关闭，确认原主线路可以连接。
3. 安排测试窗口：在主连接断开时打开“公司副连接”配置，选择 AnyConnect 公司线路，填写批准的公司 IPv4 地址 / 网段和域名；DNS 留空表示连接后自动获取。
4. 保存并连接 HY2 主线路，再连接公司内网；密码只在本机安全输入框填写。核对公司 DNS、只读业务可达性，以及公网、国内网站和局域网访问。断开副线路后检查公司范围保持阻断、主线路继续工作。

公司副连接未配置或未启用时继续使用原单线路路径；不自动导入或修改用户公司配置。配置、订阅和钥匙串保持原存储身份，现有在线更新源、公钥和团队不变。

适用于 Apple Silicon / macOS 26.0 及以上。沿用团队 RX44JC39GB 的 Apple Development 签名及 Hardened Runtime；应用 ZIP 和整个更新 feed 分别采用 Ed25519 签名。不是 Developer ID 分发签名，未经过 Apple 公证。AnyConnect UDP 历史限制未修复、未重新验收；公司副连接本阶段拒绝 UDP，不能把 HY2 / TCP 或隔离测试记作真实 AnyConnect UDP 验收通过。
