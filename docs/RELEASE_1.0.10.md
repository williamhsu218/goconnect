# GoConnect 1.0.10（build 70）

公司副连接改为按需开启：新用户的连接页默认隐藏该入口，需要时从 **设置 → 高级功能 → 公司副连接** 进入配置，保存后启用。已启用此功能的用户保留原入口和配置，不需要重新设置。

关闭功能后保留公司线路、主线路关联、网段、域名和 DNS 配置；再次开启时继续使用原有内容。取消配置不会误启用功能，保存失败也不会把已启用的公司范围隐藏。主、副连接运行中以及身份验证、清理、配置编辑或更新交接期间禁止切换，避免失去活跃通道的控制入口。

本版调整设置和入口展示，路由、DNS、隧道传输及更新安装逻辑保持原有行为。公司域名会匹配其子域名，但解析出的地址仍须落在批准的公司 IPv4 网段内；没有加入按 DNS 结果自动扩大范围的能力。

## 更新与使用

1. 可保持当前 VPN 检查、下载和验签；下载和安装由用户确认。确认安装重启后才正常断开连接并完成更新。
2. 如诊断页提示网络服务需要升级，请按正常流程升级后再连接，不会在下载更新时静默替换运行组件。
3. 不需要公司内网的用户无需开启高级功能。需要时在主、副连接均断开后完成配置，再连接 HY2 主线路及 AnyConnect 公司线路；密码只在本机输入。

已完成全量自动化回归、团队签名构建、隔离原生界面及独立旧版客户端的实际 OTA 验收。公司副连接已在有限真实场景中确认公司 DNS、内部网页与 Docker 平台登录可达；这不代表全部企业环境验收完成。公司业务目前限 IPv4 / TCP，SMB、完整故障隔离、睡眠恢复及退出清理仍需专门验收。AnyConnect UDP 历史限制未修复、未重新验收。

适用于 Apple Silicon / macOS 26.0 及以上。沿用团队 RX44JC39GB 的 Apple Development 签名和 Hardened Runtime，不是 Developer ID 分发签名，未经过 Apple 公证。应用 ZIP 与完整更新 feed 分别经原有 Ed25519 信任链签名；Bundle ID、公钥、账户和固定生产更新源不变。
