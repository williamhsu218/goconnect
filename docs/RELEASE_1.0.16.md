# GoConnect 1.0.16（build 76）

补齐已选择 App 启动的包外 Helper 与内置 CLI 的代理覆盖，保留原来的 App 与独立 CLI 配置方式。

- 名单代理模式下，可核实的包外 Helper / 内置 CLI 继承所属 App 的代理与 DNS/地址策略；全局模式下，被排除 App 的相关包外进程继承直连数据路径，系统公网 DNS 仍保持原有全局模式语义。
- 只关联同一会话用户、仍存活的 App 启动链，核实实际套接字进程、启动时间、执行映像、有效签名和 CDHash；新连接逐次复核，不把整个签名团队、目录、UID 或进程名加入名单。
- 同一 CLI 文件独立启动、由其他 App 启动时，不自动继承该 App 的规则。明确配置的独立 CLI 与直连例外仍优先；CLI 固定入口继续在正常连接时解析为实际文件路径。
- 共享 Shell/解释器、其他 App 边界、无有效签名、跨用户以及已脱离父链等无法核实的包外进程不继承，保留相应模式默认规则。可继续使用已有的独立 CLI/服务配置。

更新涉及网络组件：安装后请在“诊断”页按提示升级网络服务，再正常重连。检查、下载与验签可使用当前 VPN，明确确认安装重启后才正常断开；请先保存线路草稿。自动检查默认关闭，下载与安装由用户确认。

本版内核为固定上游源码、补丁及构建材料的 Mihomo v1.19.30-goconnect2，附对应第三方源码。实施和隔离验收见 docs/APP_CHILD_ROUTING_2026-11-10.md，最终安装与公开更新源记录见 docs/PUBLISH_1.0.16_2026-11-10.md。

适用于 Apple Silicon / macOS 26.0 及以上。沿用团队 RX44JC39GB 的 Apple Development + Hardened Runtime、既有 Ed25519 公钥及固定签名更新源；不是 Developer ID 分发签名，未经过 Apple 公证。

所选 VPS 只有 IPv4 出口，IPv6-only 端到端不属于该线路已验证的可用能力；不将 TUN 地址/路由检查等同于 IPv6-only 业务通过。公司副线按用户要求在公司 LAN 保持关闭，不冒称完成新的公司服务器认证。历史 AnyConnect UDP 偶发超时仍为已接受的非阻断限制，未重做稳定性长测；本机 UDP 回归不代表该历史问题全部修复。应用自带 DoH、未知进程及独立 DNS 保留各自边界，不承诺任意客户端零泄漏。
