# GoConnect 2.1.1（build 84）

## 设置标签页

- 打开设置或用鼠标切换标签时，只显示当前页的选中底色。
- 使用 Tab、Shift+Tab 或方向键导航到标签时显示蓝色焦点圈。滑动高亮和页面切换动画继续保留。

## 系统要求与更新

- 适用于 Apple Silicon Mac，要求 macOS 26.0 或更高版本。使用 Apple Development 团队签名和 Hardened Runtime，尚未经过 Apple 公证。
- 可从 GoConnect 菜单或设置中的「更新与关于」检查更新。下载和验签期间可以保持 VPN 连接，确认安装后应用会正常断开并重启。
- 更新后如「诊断」提示需要升级网络服务，按提示操作。 [发布规范](https://github.com/williamhsu218/goconnect/blob/v2.1.1/docs/RELEASING.md)
