# GoConnect 2.0（build 80）

## 界面与交互

- 主窗口使用 Liquid Glass 导航，连接、线路节点、流量统计、分流规则和诊断各有独立标签页。页面共用默认窗口尺寸，并记住手动调整的大小。
- 连接页保留已连接标记和呼吸灯。呼吸灯在窗口退至后台时暂停。上下行速率和连接时长以不同颜色区分，整行可展开连接详情。
- 线路节点以卡片显示。已测和未测的卡片保持对齐。删除另一条线路时保留当前草稿。
- 流量统计按分时、日、月、年显示柱状图。悬停可查看下载、上传和合计，明细仍可展开查看。
- 代理应用与服务、直连 App、直连域名与 IP 都在分流规则内管理。各子页提供各自的操作入口。直连域名与 IP 配置同时适用于按名单代理和全局模式。

## 系统要求与更新

- 适用于 Apple Silicon Mac，macOS 26.0 或更高版本。
- 沿用 Apple Development 团队签名、Hardened Runtime 和既有应用内更新公钥。本应用未经过 Apple 公证。
- 检查和下载时可保持 VPN 连接，确认安装重启后应用会正常结束连接。更新后如提示服务版本不符，请在「诊断」升级本机网络服务。
- 已在隔离 QA 验证界面与交互，生产线路验收以更新后的实际环境为准。AnyConnect UDP 的历史验收范围见发布规范。 [发布规范](RELEASING.md)
