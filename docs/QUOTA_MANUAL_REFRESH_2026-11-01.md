# 套餐用量改为手动刷新（2026-11-01）

目标：取消每五分钟刷新；需要时手动获取用量。授权失效后保留上次数据，重新授权成功后立即显示最新用量。

## 实现

- `SubscriptionUsageCard`、`YunyooUsageCard` 和 `YunyooUsageStore` 均移除定时查询；登录窗口也不再轮询用量，改用“完成登录并刷新”。
- VPS 同步脚本移除后台采集线程。已授权的订阅/用量 GET 与重新授权 POST 才触发一次采集；授权后紧接的订阅读取复用两秒内的成功结果。
- 缓存不会仅因时间经过而显示故障。实际认证失效携带 `auth_required=1`，提示重新授权；失败保留原用量及原更新时间。
- 重新授权需同步端确认已成功读取用量，再更新客户端卡片。只接收会话、尚未取得新用量不算授权验收通过。
- 云悠返回登录重定向、401/403 或登录页面时，识别为需要重新登录；其他网络故障保留可重试提示。
