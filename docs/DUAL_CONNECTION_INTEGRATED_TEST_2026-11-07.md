# 双 VPN 功能测试版（2026-11-07）

本轮仅交付测试版，不安装或替换正式 App / 服务，不发布 Releases，不更新生产 feed。当前正式版仍为 1.0.8（68）。此前的临时公司通道实测见 [独立测试记录](COMPANY_TUNNEL_LIVE_2026-11-07.md)；该证据不等于本轮系统双 VPN 已验收。

## 已接入的功能

- HY2 主线路上预留独立 AnyConnect 公司出口；公司连接独立认证、连接、断开、流量统计与恢复状态。副线路失败仅关闭所属公司流，不停止主核心。
- 公司配置使用独立 sidecar，批准明确的 IPv4 私网与公司域名；网段和域名覆盖冲突在启动前拒绝。第一阶段公司业务仅支持 IPv4 / TCP。
- 公司 DNS 可从认证后的 VPN 获取，也可手动指定。只为批准的公司域名预留系统补充解析；本地转发器通过公司隧道 TCP 查询。副线路未就绪、校验失败或退出时返回拒绝结果，不回落到公网 DNS。
- 主连接停止请求与“控制器已确认停止”分开；公司连接须取得阻断确认才结束传输，超时保留隔离状态。重复、过期和更换后端的事件不得重开旧连接。
- 连接页、菜单栏、诊断、退出和更新保护共同反映公司连接状态；公司密码仅用于当前认证，不读取正式版钥匙串。

## 单独窗口的真实系统验收

本轮不执行以下步骤；窗口由用户另行安排。

1. 记录正式连接、路由与 DNS，然后由用户主动断开正式 VPN，保留正式 App、数据和已安装服务。打开独立测试 App 并单独授权测试服务。
2. 选择 HY2 主线路及公司线路，配置用户批准的公司目标与域名。DNS 可留空，待公司服务器下发；不扩大成整个私网或默认路由。
3. 建立测试主连接后，在本机安全密码框认证公司线路；核对两个连接独立状态、实际公司 DNS 与批准范围。
4. 验证原生 macOS 公司域名解析、目标 TCP 与只读 HTTP/HTTPS，公网 / AI DNS、国内站点、LAN 和 Tailscale 路径；SMB 实际挂载 / 读取须另外完成，不能用 445 可达代替。
5. 断开副线路：批准的公司地址和域名应阻断，主线路和已有公网会话继续；重新认证应只更换公司所属代际。验证故障 / 超时 / 后端退出、睡眠恢复、正常退出与异常退出清理。
6. 断开测试双连接，确认测试 DNS 与路由清理完成，再恢复正式连接。需要移除时仅移除独立测试服务。

上述真实 TUN、系统解析、SMB、睡眠与退出清理没有通过前，不替换正式版、不发布。AnyConnect UDP 仍未修复、未重新验收，不作为本轮 TCP 范围的通过项。
