## 源码检查范围

- **配置与密码**：配置读取失败时保留原文件；保存采用原子写入；目录和敏感文件限制访问权限；记住的 AnyConnect 密码使用钥匙串。订阅缓存仍可能包含明文节点凭据，不应公开分享。
- **订阅输入**：仅接受 HTTPS 更新，限制重定向和文件大小；按允许字段提取节点，拒绝部分不支持的配置，不执行订阅中的脚本。所选节点的 `skip-cert-verify` 设置仍会被保留，不能声称所有订阅都验证服务器证书。
- **权限边界**：本机 Unix socket 限制用户，验证内核提供的对端身份及已安装组件签名；特权代码和动态依赖从 root 管理目录启动。会话检查文件权限、所有者、进程身份和存活租约。
- **网络与退出**：审阅透明分流规则顺序、原网卡出口、局域网/Tailscale 例外、公司目标、路由所有权记录及失败清理。未在当前会话重跑需要改动系统路由的测试。
- **日志**：故障记录采用固定事件与数值，限制大小并轮换；状态摘要保留应用归属和计数，不保留目标域名及 URL。
- **打包**：检查内置可执行程序、动态库引用、签名、组件版本和许可材料。源码发布不包含已生成的应用或 ZIP。

以上属于有限范围的工程审计，不代表没有其他缺陷，也不是第三方安全认证。

## 尚未完成的验收

此次为保留现有网络，没有运行需要管理员权限、真实 TUN、切换线路或中断当前会话的测试。具体包括真实 App 两种模式分流、公司内网系统连接、管理员安装/卸载、睡眠唤醒、异常退出恢复及长期稳定性。

部分用户态测试无法读取其他进程的真实路径，会明确跳过。隔离环境中的 TCP/UDP 成功不等于任意订阅、企业网关、系统代发请求或真实设备全部可用。

诊断统计修复已通过源码和隔离回归测试，但尚未在已安装的活动 VPN 会话中验证。源码生成的新组件与本机已安装组件并非相同二进制。

本次打包平台为 arm64/macOS 27，包内最低系统要求为 macOS 27。没有验证 Intel 或旧版 macOS。应用采用 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证。
