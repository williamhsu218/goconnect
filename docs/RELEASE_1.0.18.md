# GoConnect 1.0.18 (build 78)

- 修复 Mac 同时启用多张网卡时的误断和反复重连。VPN 外层的 IPv6 网关实际更换后，可触发现有线路恢复流程。
- 修复名单模式下公司域名误返回虚拟地址。公司 DNS 首选服务器超时或不可用时，可尝试配置中已有的公司备用 DNS。

- 适用于 Apple Silicon Mac，macOS 26.0 或更高版本。沿用 Apple Development 团队签名及 Hardened Runtime，应用未经过 Apple 公证。
- 检查和下载更新期间可保持 VPN 连接。确认安装重启时连接会正常结束。更新后如提示网络服务版本不符，请在「诊断」升级网络服务后重连。
