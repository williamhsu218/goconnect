# GoConnect 1.0.3（build 60）

发布日期：2026-11-06。

修复更新后无法连接 VPN 的状态残留，并允许通过当前 VPN 检查、下载和验证更新。

## 修复与行为

- 自动检查安排下一次定时任务时，Sparkle 会短暂切换会话状态。旧版只处理开始边沿，可能在更新或重新启动后误提示“先结束应用更新”。本版同步处理结束边沿，并将会话状态与安装门禁分开。
- 检查、下载和签名验证可保持 VPN 连接；这些阶段允许正常连接或断开。下载选择不等同于已开始安装，relaunch 策略查询也不再设置安装状态。
- 用户确认安装重启后，才调用原有正常断开流程。等待连接及网络服务实际停止，再交接已经下载并验证的本地更新；不因 GitHub 暂时无法访问而中断安装交接。
- 未保存线路草稿、节点测试、订阅操作或服务维护只暂停最终安装。处理完成后可明确重试。停止失败或更新取消后释放连接门禁，不强杀服务或自动重连。
- 保留此前菜单栏图标与可选双向／仅下行／仅上行速率，默认不显示速率。

## 安装与迁移

Apple Silicon；macOS 26 或更新版本。1.0.3 起可直接保持 VPN 检查和下载；确认安装时才短暂断开，重启后自行重新连接。

**已安装的 1.0.1／1.0.2 仍执行旧检查规则**，本次迁移需先按旧流程检查更新，或通过现有网络下载本页 ZIP 后正常断开、退出并替换一次。新客户端行为无法通过只修改 feed 回补进旧程序。

如诊断页提示网络组件有新版本，按正常授权流程升级本机服务。应用更新不覆盖线路、订阅或本地流量历史。

## 签名与验证边界

沿用团队 RX44JC39GB 的 Apple Development 签名、Hardened Runtime，以及既有 GoConnect Ed25519 更新密钥。ZIP 与整个 feed 分别签名；固定更新地址、公钥及团队不变。未采用 Developer ID，未做 Apple 公证。

发布门禁包括完整构建、脚本与 Swift 测试、Go race、严格嵌套签名、隔离真实 OTA、连接中检查下载到安装的状态验证、自动检查开启后的冷启动回归，以及 GitHub 附件和固定签名更新源公开读回。隔离 QA 的连接状态为模拟，不冒充生产 VPN 的长时间运行验收。

本版不更改 VPN 协议和路由核心。AnyConnect 真实 UDP 稳定性仍按用户决定跳过，未修复、未重新验收。
