# GoConnect 0.11.9（build 46）

发布日期：2026-10-16。

透明分流异常结束后，旧会话目录可能保留下来，导致后续连接虽然已建立 VPN 隧道，却被残留会话检查拒绝。此版本修复这条恢复路径，保留线路配置、订阅和钥匙串设置。

## 更新内容

- 清理前核对路由表中的精确前缀、接口、网关和 scope，保留其他网络服务替换的路由。
- 已随虚拟网卡消失的路由视为清理完成。删除返回错误时再次核对实际状态，避免误留失败记录。
- 新连接和服务安装/修复持有独占锁后，验证 root 所有权、文件权限、状态格式、进程和虚拟网卡，恢复确认失效的透明分流会话。
- 旧核心或同名网卡仍存活、记录无效、旧 company 会话和备份失败时，保留保护拦截及故障现场。
- 恢复前保留一份 root 私有的原路由记录，不复制带凭据的核心配置。现有诊断导出包含恢复时间、原状态和记录路由数。
- 增加核心退出、网络路径变化、清理和恢复阶段的脱敏事件，区分本机分流失败与 VPN 隧道退出。

此发布也包含 0.11.8 的改进：错误提示布局修复、意外断线持续提示，以及 OpenConnect 服务器断开、超时、TLS、DPD、重连和真实退出信息的分类日志。日志只保存固定事件代码和数值，不保存密码、Cookie、完整订阅地址或任意原始服务器输出。

## 安装与更新

下载 `GoConnect-0.11.9-macos-arm64.zip`，解压并替换“应用程序”中的 GoConnect。更新前先断开 VPN 并退出旧版；如「诊断」提示需要更新网络服务，请完成原生管理员授权。线路配置、订阅和钥匙串无需重建。

安装包适用于 Apple Silicon，要求 macOS 27 或更新版本，使用 ad-hoc 签名，未经过 Apple 公证。`SHA256SUMS` 提供校验值。
