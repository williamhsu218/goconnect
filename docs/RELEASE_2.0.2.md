# GoConnect 2.0.2（build 82）

## 菜单栏实时网速

- 减少 GoConnect 在后台运行时的菜单栏重绘。菜单栏宽度和布局跟随显示设置，网速图在显示内容变化时更新，悬停和辅助功能继续提供完整数值。
- 相同的每秒网速序列下，隔离原生菜单栏测试的平均 CPU 占用从 0.69% 降到 0.19%。已安装正式版的后台 CPU 占用将在更新后实测。

## 系统要求与更新

- 适用于 Apple Silicon Mac，macOS 26.0 或更高版本。使用 Apple Development 团队签名与 Hardened Runtime，应用未经过 Apple 公证。
- 在 GoConnect 菜单中选择「检查更新」。下载和验签期间可保持 VPN 连接，确认安装重启时应用会正常断开连接。更新后如「诊断」提示网络服务版本不符，按提示升级。
- 已用独立签名 App 验证从 2.0.1 在线升级。AnyConnect UDP 的历史验收范围见发布规范。 [发布规范](RELEASING.md)
