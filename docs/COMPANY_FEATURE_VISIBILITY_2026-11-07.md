# 公司副连接的可选入口

日期：2026-11-07。源码基线：默认分支 `0c3bcb4dea3f6a57b6f68c4e0bc4c11f9276c55e`，包含已发布的 1.0.9 / build 69。本记录对应未发布的界面改动；未更新版本、替换正式 App 或同步生产更新源。

## 行为

- 公司副连接默认关闭，连接页不显示相关卡片，菜单栏和诊断沿用已有的启用条件。
- 需要此功能的用户从“设置 → 高级功能 → 公司副连接”进入公司配置；配置校验并保存后才启用。取消配置不会启用功能。
- 复用已有 sidecar 的 `enabled` 字段，不新增配置版本、偏好副本或迁移。已启用的用户保留入口及配置。
- 关闭仅写入 `enabled = false`，保留公司线路、主线路关联、网段、域名和 DNS 设置。
- 主连接、副连接、公司身份验证、隔离或清理尚未结束时，不允许关闭入口；配置草稿、线路编辑或更新互斥期间也不允许修改。保存失败保留原启用状态，运行中的公司连接继续保持可见。
- 路由、DNS、隧道传输和更新安装逻辑未改动。

- `./script/build_and_run.sh --build-only --isolated-test --team-sign --run` 完成团队签名、打包和签名验证，退出码 0。使用单独 bundle、临时数据目录和测试服务身份，网络接管与服务维护停用。

## 同轮内网 Docker 连通性核对

用户报告的平台前端、同源会话 API 和后端入口均返回 HTTP 200。缺失字段的登录请求返回 422，合成账号请求返回 401；浏览器实际登录请求也在约 492 ms 收到后端 401。用户重新输入凭据后确认登录成功，随后只读观察到已登录的数据接入页和退出登录按钮。

本轮未改动 VPN 配置、服务器或业务数据库；最初超时的根因没有被进一步确定，不能将这次结果表述为修复了 VPN、Docker 或 DNS 的代码缺陷。

原始证据在项目外私有目录 `goconnect-company-feature-settings/` 和 `goconnect-company-backend/`，不提交凭据或业务数据。
