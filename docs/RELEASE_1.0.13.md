# GoConnect 1.0.13（build 73）

包含 1.0.12 的名单代理 DNS 分流和公司副连接 socket 重连修复，并补齐更新结果弹窗期间的连接心跳。

- 更新结果等原生模态弹窗长时间停留时，界面仍可响应，原心跳却未在模态循环下运行，可能在 30 秒后触发保护性断开。本版同步处理该循环中的状态检查，避免把正常弹窗当作永久卡死。
- 保留 30 秒真正无响应保护、原有 lease 文件身份校验和退出撤销。没有放宽特权服务授权、CDHash、路径或更新签名验证。
- 名单代理继续按实际 App 连接选择代理 DNS或原网络 DNS；全局模式保持代理 DoH 与直连例外。副连接仍默认关闭，socket 清理只作用于已确认停止且身份未变的本轮通道。

可以保持 VPN 检查、下载和验签；确认安装前保存草稿，再正常断开并安装重启。按诊断页提示升级网络服务后重新连接。自动下载和安装关闭；自动检查默认关闭，保留用户已有选择。公司密码仅在本机输入。

适用验收含原问题的隔离失败复现、模态循环心跳与永久卡死保护回归、真实安装后的模态弹窗停留、原名单连接和在线更新。公司服务器实网重新认证未在公司局域网内额外执行；不把隔离 CSTP socket 四轮测试称为本轮真实副 VPN 验收。

公司功能范围仍为明确 IPv4/TCP，历史 AnyConnect UDP 为“部分缺陷已修复，剩余偶发超时已接受，发布非阻断”，未重新完成该稳定性验收。App 自带 DoH、独立 DNS 查询和 Finder 内核 SMB 仍按各自边界处理。

适用于 Apple Silicon / macOS 26.0 及以上。沿用团队 RX44JC39GB 的 Apple Development + Hardened Runtime，不是 Developer ID 分发签名，未经过 Apple 公证。应用 ZIP 和完整 feed 继续由既有 Ed25519 信任链签名，固定生产地址和公钥保持不变。
