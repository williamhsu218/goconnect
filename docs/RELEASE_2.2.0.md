# GoConnect 2.2.0（build 85）

## 线路节点与诊断

- 测试订阅节点时，通过当前物理网卡直接连接该节点。节点使用域名时，通过该网卡的 DNS 解析。测试中途更换网络会显示「未测得」。节点卡片展示最近五次有效测试的成功率，已有记录可以重新测试。
- 在「诊断」中点开代理 HTTPS、代理 DoH 或原网络 HTTPS，可逐个查看实际尝试的目标、失败阶段和耗时。摘要显示整轮耗时，备用目标返回成功时单独标明。
- 在「CLI 服务连通性」中选择服务并点击「检测服务」，可通过当前代理线路查看 TLS、首字节和 HTTP 响应。检测只发送匿名 HTTPS 请求。账号授权和额度由对应服务管理。
- 内置 Mihomo 升级至 v1.19.34，保留 GoConnect 的应用识别、公司分流和 DNS 规则。线路仍由用户选择。

## 验证范围

已在真实线路上验证独立节点测速和五个 CLI 服务入口的 HTTPS 响应。隔离运行的 2.1.1 已通过 Sparkle 下载、验签、安装并单实例重启至 2.2.0，篡改的更新源在下载安装包前被拒绝。

正式安装后的验收包括名单与全局模式的系统路由、DNS 和浏览器访问，以及 VPN 连接期间的更新弹窗和草稿保护。

## 安装与更新

适用于 Apple Silicon Mac，要求 macOS 26.0 或更高版本。正式包采用 Apple Development 团队签名和 Hardened Runtime，尚未经过 Apple 公证。

在 GoConnect 菜单或设置的「更新与关于」中检查更新。下载和验签期间可以保持 VPN 连接，确认安装后应用会正常断开并重启。本版包含新的网络组件，请按「诊断 → 本机网络服务」的升级提示操作，然后重新连接。 [发布规范](https://github.com/williamhsu218/goconnect/blob/v2.2.0/docs/RELEASING.md)
