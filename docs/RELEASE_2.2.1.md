# GoConnect 2.2.1（build 86）

## 连接与诊断

- 首次发现代理探测异常时快速复测。持续异常时分别提示代理 DNS、代理 HTTPS 或线路问题。仅原网络 HTTPS 探测失败时，相关提示显示在诊断页，主连接仍显示已连接。
- 刷新订阅期间，当前会话及同一会话的切网恢复继续使用原节点参数。同名节点的新参数会在下次手动连接时生效。已从订阅移除且仍被线路引用的节点保留原配置，并在连接页和线路节点页提示。
- 系统 DNS 临时接管状态丢失时，服务先检查物理网络、路由和本地 DNS 监听，再确认旧解析器已移除且 VPN 会话仍有效。清理未确认时停止重建并记录失败。重建期间结束会话时清理已创建的解析器。
- 诊断记录可区分由主窗口、菜单栏、停止诊断、更新安装或应用退出触发的断开请求。

## 安装与兼容性

- 发布包适用于 Apple Silicon Mac，要求 macOS 26.0 或更高版本。
- 开发签名沿用 Apple Development 团队 `RX44JC39GB` 与 Hardened Runtime。包未经过 Apple 公证。更新 ZIP 和完整更新源均经 Ed25519 验签。
- 可保持 VPN 检查和下载更新。保存线路草稿后再确认安装重启。安装新版后，按「诊断」页提示升级本机网络服务。
- AnyConnect UDP 的历史偶发超时仍属已知限制。公司副连接的正式使用范围为 IPv4 / TCP。
