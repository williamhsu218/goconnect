# GoConnect 1.0.12（build 72）

本版同时修复公司副连接再次连接失败，以及按名单代理模式影响名单外应用的 DNS 问题。

- **副线重复重连**：OpenConnect 及所属 hook 退出后，只清理经过身份和权限复核、确认无人监听的本轮公司 socket。保留主线路的控制目录、路由和 DNS；活跃监听器或文件身份变化时继续拒绝移除。路径占用会提示本地通道尚未清理，不再误报为账号信息错误。
- **白名单 DNS**：系统共享查询先返回本地映射，普通应用连接仍由应用名单选择出口；代理分支交给认证代理解析，直连分支使用原网络 DNS。无需另建公司线路或新增公司域名例外。已有明确直连规则、本地域名和专用解析域保留。
- **全局 DNS**：继续使用代理 DoH 保护公网解析，保留原有直连例外；代理失败不静默回退本地 DNS。

## 更新

可以保持当前 VPN 检查、下载和验签；确认安装前保存编辑内容。本版包含网络组件修正，安装后在诊断页按提示正常升级网络服务，再重新建立连接；升级和重连安排在可短暂中断网络的窗口进行。公司密码只在本机窗口输入。

本地映射地址用于内核选路，并非服务商出口 IP。独立 DNS 工具可能看到映射地址；这不表示每个独立查询都能恢复来源 App 身份。应用自带加密 DNS、指定接口查询仍须按实际路径分别验收。原有应用名单、线路、订阅和公司配置保留。

构建、隔离核心回归、旧版真实 OTA、原生系统/App 分流及连接清理的适用验收结果见本版发布记录；不把隔离入口模拟当作真实 App 归属验收。

公司业务仍限明确 IPv4 私网及 TCP，功能默认隐藏。历史 AnyConnect UDP 为“部分缺陷已修复，剩余偶发超时已接受，发布非阻断”，未重新完成该能力的实链路稳定性验收；不扩大为全部 UDP、Finder 内核 SMB 或所有睡眠/企业环境通过。

适用于 Apple Silicon / macOS 26.0 及以上。沿用团队 RX44JC39GB 的 Apple Development 签名及 Hardened Runtime，不是 Developer ID 分发签名，未经过 Apple 公证。应用 ZIP 与完整 feed 分别通过原有 Ed25519 信任链签名，Bundle ID、公钥、账户及固定生产更新源保持不变。
