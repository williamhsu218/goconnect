# GoConnect 0.11.16（build 56）预发布版

发布日期：2026-11-05。

本版补齐 HY2 实时流量和公网出口显示，修复新增线路的界面布局，并将套餐用量改为手动刷新。

## 更新内容

- HY2 等订阅线路显示实时上下行速率及本次连接累计收发量；统计暂不可用时保留累计值并提示待更新。
- 代理线路的虚拟地址显示为“不适用”，单独通过当前线路检测和显示公网出口 IP。
- 套餐用量取消每五分钟自动刷新。手动刷新失败或授权失效时保留原数据与原更新时间；重新授权并取得新用量后立即更新。
- 官方登录窗口增加“完成登录并刷新”；支持识别登录重定向和授权过期，避免把尚未读到新用量的会话接收结果当作成功。
- 修复新建线路草稿在列表中被裁切的问题，保留保存、继续编辑和放弃更改流程。
- 改善 Cookie 拒绝等连接中断提示，并包含此前的恢复诊断和路由表解析修复。

## 已知限制

**AnyConnect 的真实 UDP 稳定性门禁仍未通过。** 既往实际连接中出现过 UDP 超时，当前证据不能将其全部归因于 GoConnect，也不能宣称已经修复。因此本版以预发布版提供，不替代已经接受的稳定版验收结论。

HY2 的真实透明分流、实时统计、出口检测，以及套餐手动刷新和过期授权恢复已在安装版验收。上述结果不代表所有企业 VPN、订阅协议、目标应用或睡眠唤醒场景均已验证。

## 下载与安装

- `GoConnect-0.11.16-macos-arm64.zip`：Apple Silicon 应用包，要求 **macOS 26 或更新版本**。包内依赖的要求高于源码的 macOS 14 部署目标。
- `GoConnect-0.11.16-third-party-sources.tar.gz`：对应第三方组件源码、补丁、构建配方、许可证、SBOM 和实际链接的 Go 依赖。
- `SHA256SUMS`：附件校验值。运行 `shasum -a 256 -c SHA256SUMS` 校验完整下载的附件。

更新前先断开 GoConnect 并退出应用，再替换“应用程序”中的旧版。在“诊断”中确认本机网络服务状态，按界面需要更新服务。线路配置和钥匙串与应用包分别保存；应用包回滚不等于用户数据回滚。

应用使用本地 ad-hoc 签名，未经过 Apple Developer ID 签名或 Apple 公证。请确认下载来源。本项目不提供关闭系统安全保护的安装方法。

自行维护云悠用量同步端的用户，应同时更新同一标签下的 `script/yunyoo_subscription_service.py`；旧同步端只接收会话的响应不能被新版视作刷新成功。登录会话仅在用户明确授权后发送到其配置的自有同步端，不进入订阅或诊断。

## 验证

发布包从已安装并验收的 build 56 应用重新归档，76 个应用文件保持一致，未以新构建替换既有实机验收结果。产品源码与该次验收源码相同。

发布前重新通过完整构建门禁：Swift 91 项测试、用量同步端 9 项测试、其余脚本回归、Go race、严格签名、运行组件及隔离集成检查。需要实际系统分流的测试按环境条件跳过；真实 HY2 和用量验证采用此前安装版记录。发布过程保留当前连接及真实用户配置。
