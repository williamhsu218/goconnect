# GoConnect 1.0.19 (build 79)

- 公司 DNS 保留已校验的域名不存在和无 A 记录答复。公司副线运行中遇到首选解析器不可用且已配置的备用服务器成功时，在当前会话内短时优先使用备用，15 秒后恢复首选顺序。
- 同线路恢复在原会话清理结束后，核对系统实际选中的默认接口和下一跳。出口稳定后启动重连。
- 诊断日志记录每个固定探测目标的 IPv4／IPv6、连接、TLS 和响应耗时，区分超时与其它失败。
- 支持 Apple Silicon Mac 和 macOS 26.0 或更高版本。沿用 Apple Development 团队签名、Hardened Runtime 和既有签名更新公钥。本应用未经过 Apple 公证。
- 检查和下载更新时可保持 VPN 连接，确认安装重启后连接会正常结束。更新后如提示网络服务版本不符，请在「诊断」升级服务并重连。
