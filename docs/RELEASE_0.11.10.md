# GoConnect 0.11.10（build 47）

发布日期：2026-10-16。

透明分流异常结束后，清理失败可能覆盖最初的退出结果，系统命令超时也缺少足够上下文。此版本补齐这条诊断链，便于区分最初触发退出的原因与随后发生的恢复错误。

## 更新内容

- 清理前记录 `session.exit_first`，最终摘要保留同一个首次原因和独立的清理结果。区分核心退出、健康检查失败、网络查询失败、路径变化、租约失效、取消和 panic。
- 系统命令记录固定类别、操作编号、耗时、超时上限，以及可用的退出码、信号和 errno。成功慢命令与超时后的迟到结果分别记录。
- 路由清理记录读表、删除、复核和状态写入的具体失败阶段，只保留路由序号、地址族、前缀长度、scope 和网卡类别信息。
- 独立的 `worker.exit.json` 保存最近退出摘要，不随普通日志轮转或临时会话目录清理消失；首次和最终记录使用独立队列位置。
- 诊断导出附带新事件和字段说明。所有新增内容均经过固定类别与网卡名过滤，不保存命令参数、原始输出、任意错误文本、令牌、密码、订阅地址或访问目的地址。

继续保留 0.11.9 的残留会话恢复修复，路由策略、6 秒系统命令上限、线路配置、订阅和钥匙串设置不变。诊断增强不能补回旧版本未记录的首次原因；SIGKILL、断电或文件系统无法写入时，仍需结合服务和系统日志分析。

## 安装与更新

下载 `GoConnect-0.11.10-macos-arm64.zip`，校验 `SHA256SUMS` 后解压并替换“应用程序”中的 GoConnect。更新前先断开 VPN 并退出旧版，再在“诊断”中更新本机网络服务并完成管理员授权。无需重建现有配置。

适用于 Apple Silicon，要求 macOS 27 或更新版本。安装包使用 ad-hoc 签名，未经过 Apple 公证。

## 验证范围

- Swift 60 项测试、Go race、`go vet`、原生构建、严格签名与运行组件依赖检查。
- 阻塞命令超时及迟到结果、真实子进程退出码与信号、租约和健康检查失败分类、清理多阶段失败、panic 传播、队列拥塞及安全文件保护。
- 组合回归覆盖“命令超时 → 清理失败 → 日志轮转 → 首次退出原因仍可读”；内置 OpenConnect 的隔离 TCP、UDP、证书及断开诊断验证。
- 本机安装后 76 个 App 文件与候选一致，17 个特权服务运行文件与 App 内组件一致；9 个现有配置/缓存文件哈希不变，界面显示 0.11.10、未连接且服务就绪。
- 实际从新版界面导出诊断摘要，确认新字段说明和服务日志包含在内，文件权限为 `0600`。

未在真实 VPN 中注入故障，未覆盖所有目标 App、睡眠唤醒、内核卡死、Intel Mac 或较早系统场景。详见[诊断字段说明](DIAGNOSTICS.md)。
