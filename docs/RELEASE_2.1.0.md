# GoConnect 2.1.0（build 83）

## 设置窗口

- 设置分为「通用」「高级」和「更新与关于」，适配浅色与深色模式。
- 「通用」可开启登录 macOS 时自动启动，并可预览菜单栏的网速和方向显示。VPN 连接由用户发起。
- 「高级」汇总公司副连接、本机数据目录与特权网络服务状态。在配置暂时只读时会显示原因。
- 「更新与关于」可检查更新、复制版本信息、查看隐私与存储说明，并在 Finder 打开第三方开源组件的许可目录。

## 系统要求与更新

- 适用于 Apple Silicon Mac，要求 macOS 26.0 或更高版本。应用使用 Apple Development 团队签名和 Hardened Runtime，尚未经过 Apple 公证。
- 可从 GoConnect 菜单或「更新与关于」检查更新。下载和验签期间可保持 VPN 连接。确认安装时应用会正常断开连接并重启。
- 更新后如「诊断」提示网络服务需要升级，按提示操作。AnyConnect UDP 的历史验收范围见发布规范。 [发布规范](RELEASING.md)
