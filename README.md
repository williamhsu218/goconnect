# GoConnect

让 Mac 上的不同应用，走你选择的网络。

GoConnect 是一款 macOS 网络连接工具。你可以接入公司的 AnyConnect VPN，也可以使用已有的 Clash YAML 订阅，然后决定哪些应用走这条线路、哪些继续使用原来的网络。

它不提供 VPN 账号或订阅，需要使用你自己的服务。

## 可以做什么

- **只让指定应用走 VPN**：把应用加入白名单，其余应用正常直连。
- **让大多数应用走 VPN**：选择全局模式，再把不需要代理的应用加入直连名单。
- **给网站和 IP 设置例外**：例如让某些网站始终使用原网络。
- **管理多条线路和订阅节点**：保存常用连接，手动更新订阅，测试节点是否可用。
- **访问公司内网**：使用 AnyConnect 时，可以添加明确的公司 IP 或网段，供 Finder 文件共享、SSH 等使用。
- **从菜单栏查看状态**：快速打开主窗口、连接或断开。

应用正常打开即可，不用逐个填写代理地址。名单也支持独立的命令行程序，按所选可执行文件的完整路径匹配。

## 开始使用

目前仓库提供源码，尚未提供面向普通用户的安装包。熟悉开发工具的用户可以按[构建说明](docs/BUILD.md)生成应用。

构建后，将 `GoConnect.app` 放入“应用程序”文件夹并打开：

1. 在“线路配置”中填写 VPN 服务器和账号，或在“订阅管理”中添加 HTTPS 订阅地址。
2. 选择“App 白名单”或“全局模式”，设置需要走 VPN 或保持直连的应用。
3. 返回“连接”页，选好线路并打开连接开关。
4. 首次连接需要授权安装本机网络服务。之后普通连接通常不再询问管理员密码；更新网络组件时可能需要重新授权。

连接期间应用名单只读。修改名单或线路规则前，先断开连接，保存后重新连接。GoConnect 不会替你打开或重启其他应用。

## 使用前需要知道

**系统要求**：当前源码版本为 0.11.4。本次验证使用 Apple Silicon Mac 和 macOS 27；在这台机器生成的应用要求 macOS 27 或更新版本。虽然 Swift 项目最低目标设为 macOS 14，最终要求还取决于打包进去的网络组件。Intel Mac 和较早系统尚未完成本次验证。

**公司 VPN 和订阅用途不同**：普通订阅节点不能代替公司 VPN 访问公司内网。需要浏览器登录、复杂多因素认证或专用客户端功能的企业 VPN，也可能无法使用。

**分流存在边界**：部分请求由 macOS 的共享进程代发，无法准确归属到某个应用。识别不到进程时，全局模式走所选线路，白名单模式保持直连。域名规则也无法覆盖所有加密或纯 IP 请求。

**本地网络优先**：会保留已识别的局域网和 Tailscale 路径，但不同 VPN 同时接管网络可能发生冲突。公司内部域名的专用 DNS 解析尚未实现。

**连接中断后**：GoConnect 会尝试撤销本次添加的路由。它不是“断线后禁止所有联网”的工具；如果清理失败，会暂停重连并保留诊断信息。

## 账号与本机数据

选择“记住密码”后，AnyConnect 密码保存在 macOS 钥匙串。线路配置和订阅缓存保存在本机；订阅缓存可能含有节点密码或其他凭据，请勿直接上传或分享。

GoConnect 不会把你的线路配置上传到本项目。连接 VPN、更新订阅和手动测试节点时，会访问相应服务；节点测试会通过所选节点访问 Google 的连通性测试地址。

本地构建使用临时签名，未经过 Apple 公证。遇到系统提示时，请先确认应用来源。本仓库不提供关闭系统安全保护的安装方式。
