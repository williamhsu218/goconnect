## 简介

GoConnect 是一款使用原生 SwiftUI 构建的 macOS 网络连接与分流工具，当前发布包面向 Apple Silicon Mac，要求 macOS 26.0 及以上。

应用支持接入用户自备的 AnyConnect VPN 服务凭据，或 Clash YAML 格式的 HTTPS 订阅（Hysteria 2 订阅已完成真机实测）。**GoConnect 不提供 VPN 服务、节点、账号或订阅**，需要使用你自己的服务。

## 核心特性

- **精密原生界面**：采用轻量紧凑的 SwiftUI 浅色精密布局，原生适配深色模式，常驻菜单栏提供实时状态概览。
- **可选菜单栏速率**：新单色路径图标保留连接状态，快捷菜单可直接打开“设置…”（⌘,）；在设置中开启“显示网络速率”，可选下行与上行、仅下行或仅上行，默认关闭。双向上下两行、单向居中一行，保留 KB/s、MB/s 等单位的紧凑排版，固定最大宽度并收紧外侧留白；悬停显示完整数值，实时速率变化不带动邻近菜单项，偏好自动保留。
- **按名单代理与全局模式**：
  - 选择“**按名单代理**”，在“代理名单”中添加应用或独立 CLI 服务，其余应用保持直连。CLI 可选固定入口，连接时解析实际可执行文件的完整路径；连接期间升级独立 CLI 后需重新连接。1.0.16 增加按活跃启动链、会话用户及签名核实的包外 Helper / 内置 CLI 覆盖，独立 CLI 与直连例外仍优先；无关 App、共享解释器及无法核实的进程不自动继承。
  - 支持全局模式与直连名单，提供域名与 IP 例外配置，以及明确的企业内网网段分流。
- **HY2 可靠 DNS**：经过 HY2 代理的公网 UDP DNS 查询由节点内核转为经所选线路发送的 DoH，减少 UDP 回程丢包导致的解析超时。节点内部可靠解析继续保留，其他 UDP 保持原有路径。
- **按模式区分 DNS**：全局模式的公网域名默认经代理 DoH；按名单代理模式先返回本地映射，再随应用连接的出口解析，名单内走代理、名单外使用原网络 DNS。已有直连例外、本地域名和专用解析域继续保留。1.0.15 修复延迟解析与 CIDR/LAN/主线路网段规则漏匹配，保留名单内外的 DNS 去向；停止返回虚拟 ULA IPv6，避免公网网站误触发浏览器本地网络权限；真实内网 IPv6 保留。临时 DNS 记录随连接撤销，不改写网络偏好。
- **公司副连接（可选，默认隐藏）**：从“设置 → 高级功能 → 公司副连接”配置并开启；已启用用户保留入口，关闭后保留配置。支持 HY2 主线路之上连接独立 AnyConnect 公司线路，配置明确 IPv4 私网和公司域名，DNS 可在认证后从服务器获取。当前公司业务限 IPv4 / TCP；修复了连接未释放导致容量耗尽、浏览器复用失效连接及退出后残留本地 socket 阻止重连的问题；SMB、完整故障隔离、睡眠恢复及退出清理仍待专门验收。
- **本机流量观测**：
  - 连接页显示当前上下行速率；按线路记录上传、下载及合计用量。
  - 支持按分时、日、月、年等多维度浏览历史趋势；切换统计查看线路不会变更当前活跃的网络连接。
  - *说明：此统计来自本机 GoConnect 的采样记录，不是服务商剩余套餐余额；不包含其他设备、其他客户端或开始记录前的历史，采样、协议开销与服务商计费也可能存在差异。*
- **内置安全在线更新**：
  - 自 v1.0.1 起集成 Sparkle 签名更新体系，安装包与更新发布 Feed 均具备独立 Ed25519 签名校验。
  - 检查、下载与验签可使用当前 VPN；确认安装重启后，才正常断开连接并交接安装。

## 下载与安装

### 系统要求

- **芯片架构**：Apple Silicon (arm64)
- **系统版本**：macOS 26.0 及更高版本（源码部署目标 14.0 仅作工程基础约束，完整包的实际要求见对应版本的发布说明；Intel 平台未经验收）

### 获取应用

- **最新发布包**：[GoConnect-1.0.16-macos-arm64.zip](https://github.com/williamhsu218/goconnect/releases/download/v1.0.16/GoConnect-1.0.16-macos-arm64.zip)
- **完整发布页**：[GitHub Releases / Latest](https://github.com/williamhsu218/goconnect/releases/latest)

### 首次安装与权限

1. 下载并解压 ZIP 文件，将 `GoConnect.app` 移至 `/Applications` 目录。
2. 首次发起网络连接时，根据系统提示完成本机网络辅助服务的授权；常规连接过程中不会频繁弹出管理员权限请求。
3. **从 0.11.17 及更早版本迁移**：旧版本未集成在线更新模块。首次升级至 1.0.1 时，请先在旧版中正常断开 VPN 并完全退出应用，手动替换 `/Applications` 中的文件；此后版本即可直接在应用内检查更新。

> **签名说明**：当前发布包采用 **Apple Development 团队开发签名**并启用 Hardened Runtime，未采用 Developer ID 分发签名，未经过 Apple 公证。更新 ZIP 和完整 feed 另经 Ed25519 签名校验。请从本项目 GitHub Releases 获取应用。

## 开始连接

1. 在“线路配置”中填写 AnyConnect 服务器和账号，或在“订阅管理”中添加 HTTPS 订阅地址。
2. 选择“按名单代理”或“全局模式”，配置代理名单、直连名单及例外规则。
3. 回到“连接”页选好线路，打开连接开关。修改名单或线路规则前先断开，保存后重新连接。

## 应用内检查更新

自 v1.0.1 起，后续正式版可直接在应用内更新：

1. 可保持 VPN 连接，先保存线路草稿；当前线路可用于访问 GitHub。
2. 在 **GoConnect 菜单或设置 → 检查更新**。
3. 确认下载后，应用验证签名。点击安装重启时才正常断开 VPN，等待网络服务停止后安装；重启后可重新连接。

1.0.1／1.0.2 旧客户端仍要求先断开才能检查；本次迁移需按旧流程更新一次，或从 Releases 下载后正常退出并替换。1.0.3 起生效上述连接中更新流程。

自动检查默认关闭，可在设置中开启；下载和安装仍由你确认。新版涉及网络组件变化时，按诊断页提示正常升级本机网络服务，可能需要管理员授权。

## 边界与已知限制

在日常使用前，请留意以下边界：

- **1.0.16 本轮验收范围**：名单与全局模式按 IPv4/TCP 放行。测试所选 VPS 仅提供 IPv4 出口，IPv6-only 端到端未通过，需在支持 IPv6 出口的环境另行验收；公司副线按要求未在公司 LAN 重做实链路认证。详见 [本轮发布与验收记录](docs/PUBLISH_1.0.16_2026-11-10.md)。

- **AnyConnect UDP 稳定性**：此前已修复部分本地缺陷，历史偶发超时尚未证明彻底消除，也未重新完成实链路稳定性验收。用户于 2026-11-07 接受该限制，在业务不依赖 UDP 的前提下按发布非阻断处理；公司副连接仍仅支持 IPv4 / TCP。后续修改或重新使用该能力时另做验收，详见[发布规范](docs/RELEASING.md)。
- **公司副连接验收边界**：默认隐藏，设置中按需开启。本机已验证 320 次连续请求、重连后 64 次请求、历史账本切换、公司 DNS / 网页 / Docker、仅断开公司时的阻断与主线保持，以及正常退出清理。公司业务限 IPv4 / TCP；Finder 内核 SMB、崩溃与睡眠恢复、其他企业环境仍需针对性验收。详见 [1.0.11 发布与验收记录](docs/PUBLISH_1.0.11_2026-11-07.md)。
- **分流识别**：部分请求由 macOS 共享进程代发，无法准确归属到某个应用；域名规则也无法覆盖所有加密或纯 IP 请求。识别不到进程时，按名单代理模式保持直连，全局模式走所选线路。
- **网络与认证**：保留已识别的局域网与 Tailscale 路径，在本应用之外同时运行其他 VPN 仍可能冲突。不保证断线后阻断所有联网，也未覆盖全部企业认证流程；订阅节点不能代替公司 VPN 访问内网。

## 隐私与数据安全

- **本地存储**：线路配置、订阅缓存与流量历史保存在本机；订阅缓存可能包含节点凭据。
- **凭据管理**：AnyConnect 密码仅在用户主动勾选“记住密码”时写入系统钥匙串（macOS Keychain）。
- **外部请求**：GoConnect 不会把你的线路配置上传到本项目。连接、订阅更新、节点测试及 GitHub 软件更新会访问各自的服务；节点测试会访问连通性测试地址。系统 DNS 保护及 HY2 节点内公网 DNS 解析会经所选节点访问 Cloudflare 和 Google 的 DoH 服务。
- **问题反馈**：提交 Issue 或日志前移除密码、节点凭据、完整订阅链接及公司服务器信息。
